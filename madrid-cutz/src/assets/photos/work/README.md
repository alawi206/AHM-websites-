# Gallery photos

Drop real Madrid Cutz haircut photos here (JPG, PNG, WebP or AVIF, ideally 1600px+ on the long edge).
They appear in "The work speaks for itself" automatically — resized and re-encoded to AVIF/WebP at build time, never cropped.

Name each file with a category prefix so the filters work:

| Prefix    | Filter      | Example            |
| --------- | ----------- | ------------------ |
| `fade-`   | Fades       | `fade-01.jpg`      |
| `taper-`  | Tapers      | `taper-03.jpg`     |
| `beard-`  | Beard Work  | `beard-02.jpg`     |
| `style-`  | Styles      | `style-textured.jpg` |
| `kids-`   | Kids        | `kids-01.jpg`      |

Anything else lands under "Cuts". Only use photos of real Madrid Cutz work that the shop has approved.
