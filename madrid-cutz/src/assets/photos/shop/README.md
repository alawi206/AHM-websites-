# Shop photos

Optional, but they make the biggest difference. Use real photos of the shop:

- `hero.jpg` — full-screen hero backdrop (landscape, 2400px+ wide). Replaces the rendered hex-light ceiling.
- `about.jpg` — "More than a haircut" image (portrait 4:5). The LED ceiling over the chairs is ideal.
- `visit.jpg` — storefront / entrance, shown on the map card (landscape 4:3).

For a hero film, put a short muted loop at `src/assets/video/hero.mp4` (or `.webm`) — keep it under ~6 MB.
